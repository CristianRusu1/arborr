08
Frequently asked

Answers, up front.

Is technical expertise required?
None. Arborr is designed for business users. If you can articulate what you need to see, Arborr will produce the report. Advanced users retain the ability to review and refine the underlying logic.
Which data sources are supported?
Arborr connects to the operational databases most organizations already rely on, alongside uploaded CSV and spreadsheet files. Multiple sources can be combined within a single report.
How do we verify the numbers?
Each report exposes its sources and the logic that produced it. Reports are versioned, so a definition saved today will return identical figures when regenerated next quarter.
Who has access to shared reports?
Only the recipients you authorize. Share links are private by default, support passcode protection and scheduled expiry, and can be revoked at any time.
How does Arborr differ from a traditional BI tool?
Conventional BI tools require you to anticipate the question and construct a dashboard to answer it. Arborr allows questions to be posed as they arise — and returns a completed report rather than a blank canvas.
